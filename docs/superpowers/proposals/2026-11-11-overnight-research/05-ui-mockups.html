GrayMatter: предложения по интерфейсу

Пять главных предложений из отчёта 05-ui-ux.md, телефон и компьютер рядом. Цвета, шрифт и скругления взяты из текущих токенов main.css. В тёмной теме уже применена правка G1: выделение полупрозрачным индиго вместо тёмно-синей плашки, поверхность слоёв светлее фона, заметная подсветка совпадений. Интерфейс на английском, как в приложении, подписи на русском. Данные выдуманные.

1 · Степпер с накоплением нажатий и отменой до записи

B1 + B3 + A1 + G2 + E4

Нажатия «−» и «+» копятся на устройстве и показываются отдельной отметкой «ждёт записи». Через 2 секунды после последнего нажатия уходит одна запись в журнал. Пока запись не ушла, её можно отменить из плашки над нижней панелью. Подтверждённое число меняется только после ответа базы: это не оптимистичное обновление. «Count» (поставить число) теперь на виду. На телефоне можно нажимать: это работающий пример.

2 · Варианты: число внутри степпера, значения атрибутов на виду

B4 + D3

Значение стоит между своими «−» и «+», а имя варианта получает место и не обрезается. Нажатие на имя открывает лист варианта со всеми действиями, поэтому «⋯» на телефоне не нужно. Вместо «Differs by variant» видны сами значения. На компьютере варианты — маленькая таблица со столбцом на каждый атрибут, степпер появляется при наведении.

3 · Действия прямо из палитры: «есть ли TL072?» → «потратил 2» без перехода

E2 + E1 + D1

Главный сценарий закрывается в одном окне. На компьютере Tab на выбранном предмете открывает панель действий справа, как в Raycast, с клавишами. На телефоне долгое нажатие на результат раскрывает его на месте: степпер и «Use… / Receive… / Open» прямо над полем поиска, под большим пальцем.

4 · Архив без подтверждения — с отменой; свайп по строке

C1 + A1 + A5

Архив обратим по устройству данных (restore по archiveId), поэтому вместо листа «Вы уверены?» действие выполняется сразу, а в плашке есть «Undo». Подтверждение остаётся только для необратимого: удаление навсегда, удаление атрибута со значениями. Свайп влево по строке открывает «Use 1» и «More». Это только ускоритель: те же действия есть в долгом нажатии и в карточке. Свайп вправо по-прежнему открывает меню.

5 · Списки: монограммы, сводка по вариантам, сортировка, плотная таблица

D1 + D2 + D4 + D5

Пока нет фото, у предметов есть монограммы, и строки различаются по форме. У предметов с вариантами в подстроке видно, каких номиналов сколько, а пустые помечены «—». «Out» — нейтральная метка у числа. Над списком — тихая сортировка и «сначала в наличии». На компьютере есть режим таблицы и «включая подпапки», как «All items» в Sortly. Сетка с фото включится после плана 4.

Три визуальных направления

раздел 4 отчёта

Одна и та же строка списка в каждом направлении, светлая и тёмная. Структура, шрифт Manrope и нейтральные действия везде одинаковы. Меняются температура нейтральных цветов, скругления и то, как выглядят числа. Рекомендация: A сейчас, детали C (моноширинные числа и «светодиоды») — как тема после MVP.
